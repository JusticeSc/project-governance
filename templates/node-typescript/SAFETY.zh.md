# 安全

[English](SAFETY.md) | 中文

## 实验性状态

本工具包是开发者预览软件。它尚未接受安全审计，不得视为安全或可用于生产环境。

生成器会读取远端包与仓库数据，并向你指定的路径写文件。它不执行包代码、不安装包、不检出工作树，但缺陷、恶意包元数据、不可信 registry 或不可信 Git 服务器仍可能产生误导性的索引或泄露数据。

## 工具会访问什么

- **网络。** 生成器请求 npm registry 文档与 tarball，并对每个列出的仓库运行 Git。它不应用 `.npmrc` 中的 registry token；Git 从不提示输入凭据，私有仓库必须通过凭据助手或 SSH agent 可读。
- **本地文件。** 它读取来源列表，写出索引，在索引旁边的 `icons/` 下写出大图标，并在输入列表旁维护缓存。它只删除其输出目录中它能识别的、由自己生成的图标文件。
- **包内容。** tarball 在大小上限与完整性校验下于内存中读取。Git 对象被抓取到私有的临时裸仓库并以 blob 读取；钩子、文件系统监视、子模块以及除 HTTPS 与 SSH 之外的所有传输均被禁用，继承的 `GIT_*` 变量除 `GIT_SSH` 与 `GIT_SSH_COMMAND` 外全部丢弃。

## 信任边界

索引是未经认证的数据。标题、作者、标签、评分、包名、版本与 `engines` 值都是包或市场自述；一个被列出的仓库可以自称任意包名。发布前请审查来源列表与渲染后的索引，并通过 HTTPS 发布。客户端必须显示索引 URL 与每个版本的安装来源。

校验器检查文档结构与规则；它无法验证某个版本的元数据与其描述的包一致，也无法验证包本身是否安全。它同样不限制文档大小；调用方必须自行设限。

## 负责任地使用

- 只授予进程所需的文件系统、网络与 Git 访问权限。
- 读取不可信仓库时，优先使用一次性环境。
- 备份工具可能修改的输出与缓存目录。
- 不要在来源列表或索引中发布凭据或私有仓库 URL。
- 发布前审查生成的图标与本地化文本。
