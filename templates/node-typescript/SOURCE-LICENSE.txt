The distributed subset is limited to the plugin market index generator
(apps/plugin-market-generator), its format-1 validator
(packages/util/plugin-market-index), and the Node/TypeScript workspace tooling,
documentation, and agent workflow retained around them. Unrelated product
applications, packages, documentation, vendored frameworks, SDKs, native code,
benchmarks, and product assets are not part of this subset.

Changes made in this copy:

  - Removed the unrelated product workspaces and their documentation.
  - Moved the LocalizedText type from the removed package-manifest package into
    packages/util/plugin-market-index/src/types.ts, which is now its only
    definition.
  - Adapted the root workspace manifests, TypeScript and lint configuration,
    build and gate scripts, and Git hooks to the two retained workspaces.
  - Rewrote the retained user and developer documentation around the generator
    and validator; the plugin market index format Agent Note is retained as the
    format contract. This file owns the copied material's source provenance.
  - Retained the agent workflows, documentation standards, test policy, and
    review guidance that are not specific to the removed product behavior.
  - Made workspace discovery, aliases, shared version and license checks
    independent of the example's names; separated reviewed project policy
    from gate implementations and placed business artifact tests with owners.
  - Added direct new-project and complete example-replacement instructions.
  - Added verify-package-export-keys as a supplemental template checker for
    the source's reviewed export-key rule, not as a copied source executor.
    The policy manifest records keys, owners, and reasons; rule changes and
    domain-owner confirmation remain review responsibilities.
