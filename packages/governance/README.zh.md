# 治理能力包

[English](README.md) | 中文

## 概述

定位拥有检查或安装操作的包。这些包不依赖CLI应用；应用选择其声明的公开接口。

## 包

| 包 | 拥有 |
|---|---|
| [checks](checks/README.zh.md) | 可信策略校验、命令执行及失败传播。 |
| [documentation](documentation/README.zh.md) | 声明语料的Markdown、配对、包文档和编译器支持的检查。 |
| [distribution](distribution/README.zh.md) | 运行文件选择及独占、不覆盖的Skill安装。 |
